# Setup Guide

## Option A — Docker Compose

Recommended for reproducing the complete application.

```bash
git clone https://github.com/Ayushkumar20045/image-quality-ai.git
cd image-quality-ai

docker compose build
docker compose up -d
```

Verify:

```bash
docker compose ps
```

Open:

```text
http://localhost:5173
```

Check backend:

```bash
curl http://localhost:8000/health
```

Expected:

```json
{
  "status": "healthy"
}
```

Stop:

```bash
docker compose down
```

## Option B — Local Development

### Backend

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
uvicorn backend.app.main:app --reload --port 8000
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## CLI

From repository root:

```bash
python -m ml.src.predict ./frontend/src/assets/hero.png
```

## Training

Training requires the processed feature splits generated by the dataset pipeline.

```bash
python -m ml.src.train
```

The training process compares candidate models and saves the best pipeline for each target according to validation Macro F1.

## Evaluation

```bash
python -m ml.src.evaluate
```

Evaluation expects the processed test feature file and writes reports under:

```text
ml/data/processed/evaluation/
```
